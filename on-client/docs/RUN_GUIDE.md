# 다아트(케셰브) 실행 안내 한 장

처음 보는 사람이 이 한 장만 보고 앱을 켜고 첫 화면을 확인하는 안내입니다. 포장(설치형) 없이 프로젝트 폴더에서 실행합니다.

## 준비 (한 번만)

- Windows PC
- **Node.js 22~24** (수업 기준 24.19.0). PowerShell에서 `node -v`를 입력해 `v22.x`~`v24.x`가 나오면 됩니다. 없으면 https://nodejs.org 에서 설치한 뒤 **새** PowerShell 창을 엽니다.
- 따로 설치할 패키지는 없습니다. `npm install`은 하지 않아도 됩니다(외부 라이브러리를 쓰지 않음).
- 관리자 권한은 필요 없습니다.

## 1. 프로젝트 폴더를 엽니다

1. 파일 탐색기에서 앱 폴더의 `on-client` 폴더로 갑니다. 예: `D:\claude code\Daat-blockage\on-client`
   - GitHub에서 ZIP으로 받았다면 풀린 폴더 안의 `Daat-blockage\on-client`입니다.
2. 탐색기 위쪽 주소창을 누르고 `powershell`이라고 입력한 뒤 Enter를 누릅니다. 그 폴더에서 PowerShell 창이 열립니다.

## 2. 앱을 켭니다

PowerShell 창에 아래 한 줄을 붙여 넣고 Enter를 누릅니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

`케셰브가 켜졌습니다. 브라우저에서 http://127.0.0.1:5189/ 을 여세요.`가 나오면 성공입니다. 이 창은 닫지 말고 그대로 둡니다.

## 3. 첫 화면을 확인합니다

1. 브라우저에서 `http://127.0.0.1:5189/`를 엽니다.
2. 「보호 현황」 탭에서 「관제 대시보드」와 상태 카드 4개가 보입니다.
3. 「내 PC 실측 조회」를 누르면 「내 PC」 카드가 「실측 6/6」이 됩니다.

「기존 서버(SDP) 연결」 카드의 「SDP 미연결」은 SDP 설정 없이 켰기 때문에 나오는 정상 표시입니다. 고장이 아닙니다.

끄기: PowerShell 창에서 **Ctrl+C**.

## 값 표시 읽는 법

- `실측`: 이 PC에서 방금 읽은 값입니다.
- `예시(실제 조회 아님)`: 설명용 고정 값입니다. 「예시 보기」를 눌렀을 때만 나옵니다.

## 막혔을 때

| 보이는 문구 | 할 일 |
|---|---|
| `Node.js 가 없습니다` | nodejs.org에서 Node.js 24.19.0을 설치하고, **새** PowerShell 창에서 1번부터 다시 |
| `지금 Node.js 는 vXX 입니다. 앱은 Node.js 22~24 에서 실행합니다` | Node.js 24.19.0을 설치한 뒤 새 창에서 다시 |
| `참고: 지금 Node.js 는 ... 수업 기준은 v24.19.0` | 안내일 뿐입니다. 그대로 진행해도 됩니다 |
| `앱 폴더가 아닙니다` | `on-client` 폴더 안에서 PowerShell을 열었는지 확인 |
| `포트 5189 를 다른 프로그램이 쓰고 있습니다` | 앱이 이미 켜져 있을 수 있습니다. 브라우저로 먼저 열어 보고, 아니면 명령 끝에 ` -Port 5190`을 붙여 실행하고 `http://127.0.0.1:5190/`을 엽니다 |
| 스크립트 실행이 막혔다는 빨간 글자 | 명령을 직접 입력하지 말고 2번의 한 줄을 그대로 붙여 넣습니다(`-ExecutionPolicy Bypass`가 이번 한 번만 허용합니다) |
| `앱 서버가 20 초 안에 뜨지 않았습니다` | 창의 메시지를 캡처해 앱 만든 사람에게 보냅니다 |
| 브라우저가 열리지 않음 | PowerShell 창이 아직 열려 있는지 확인. 닫혔다면 2번부터 다시 |
| 화면이 예전 모습 | 브라우저에서 **Ctrl+F5** |
