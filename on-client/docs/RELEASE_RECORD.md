# 다아트 재현 기록과 릴리스 기록 (22단계)

이 문서는 학생 「다아트」가 22단계에서 작성한 학생 문서입니다. 확정한 커밋을 별도의 새 폴더에 받아 21단계 설명서(`docs/STUDENT_RUNBOOK.md`)대로 실행하고, 화면에서 본 결과만 적었습니다. 제공 파일은 고치지 않았습니다.

표기 규칙은 21단계 설명서와 같습니다.

- **재현됨**: 새 폴더의 실제 화면이나 PowerShell에서 같은 결과를 직접 봤습니다.
- **연결 없음**: 화면 표시는 재현했지만, 연결된 시스템이 없어 실제 기능은 동작하지 않았습니다.
- **확인 불가**: 이번 재현에서 확인할 수 없었습니다.
- **재현 안 됨**: 같은 절차로 해 봤지만 결과가 달랐습니다. 이번 재현에서는 해당 항목이 없습니다.
- **모의 점검**: 학생 함수에 모의 입력을 넣어 Node로 점검했습니다. 실제 연결이 아니며 이번 재현 결과에 넣지 않았습니다.

## 6. 지원 범위와 미확인(UNV)

지원하는 것(이번 재현에서 확인):

- Windows PowerShell과 Node.js v24.21.0에서 시작·종료·재실행
- 연결 없음 상태에서 13~20 학생 카드의 상태 표시

미확인(UNV), 성공이나 정상으로 보지 않음:

- SDP 연결, 실제 사용자·기기·세션·업무 앱 판정·보안 기록
- 계정 연결, AI 앱 승인, AI 연결 점검과 사건 설명
- 조치 준비·집행·결과 재조회
- 실제 OSV 조회와 package-lock 버전 대조
- 종료 중 「연결할 수 없음」 화면, `-Port`·`-Demo`·`-Background`, `npm.cmd` 실행
- 공식 단계 판정 결과
