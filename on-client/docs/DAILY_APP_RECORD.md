# 다아트 매일 쓰는 앱 기록 (권장 제작 기간)

이 문서는 학생 「다아트」가 권장 제작 기간(2026-10-26~11-06)에 쓴 학생 문서입니다. 21단계 설명서(`STUDENT_RUNBOOK.md`)와 22단계 기록(`RELEASE_RECORD.md`)은 고치지 않았습니다.

- 화면 틀: **관제 대시보드형**(맨 위 상태 카드 네 개, 아래 추이와 기록)
- 포장 형태: **포장 없이 프로젝트 폴더에서 실행**. `npm run package-app`과 설치 명령은 실행하지 않았습니다.
- 버전: 시작 틀 0.2.21 기반의 **검증 중인 버전**입니다. v1.0이 아닙니다.

## 1. 값의 구분

| 표시 | 뜻 | 어디에 나오나 |
|---|---|---|
| `실측` | 이 PC 또는 이 앱 서버가 이번에 돌려준 값 | 상태 카드 4개, 내 PC 실측과 추이, 이상 징후 근거 기록 |
| `예시(실제 조회 아님)` | 설명용 고정 값. 이 PC에서 잰 값이 아님 | 「예시 보기」를 누를 때만 나오는 「예시 화면」 표. 칸마다 「(예시)」가 붙음 |

예시 값은 상태 카드, 추이 표, 이상 징후 기록에 섞지 않습니다. 기본은 꺼져 있습니다.

## 2. 고른 핵심 기능 세 가지

| # | 기능 | 하는 일 | 하지 않는 일 |
|---|---|---|---|
| 1 | 상태 카드 4개 | 내 PC, 기존 서버(SDP) 연결, AI 연결, 설치 패키지 조회를 카드마다 상태·확인 시각·다음 행동·출처로 보여 줍니다. | 받지 못한 값을 정상·안전으로 바꾸지 않습니다. |
| 2 | 내 PC 실측과 추이 | 「내 PC 실측 조회」를 누를 때만 `/api/pc/status`를 한 번 읽습니다. 최근 10회를 표로 쌓고 CPU 변화(%p)를 보여 줍니다. | 자동으로 다시 읽지 않습니다. 저장하지 않으며, 새로고침하거나 앱을 끄면 사라집니다. 1분이 지난 값은 「오래됨」으로 표시합니다. |
| 3 | 이상 징후 근거 기록 | 알림, 꺼진 방화벽 프로필, Windows 오류 건수, 높은 CPU·메모리, 적은 디스크 여유를 출처·시각·「이것만으로 말할 수 없는 것」과 함께 나열합니다. | 판정하지 않습니다. 관찰이 없다고 「이상 없음」으로 쓰지 않습니다. |

## 3. 바꾼 파일

| 파일 | 내용 |
|---|---|
| `student/extension.mjs` | `renderStatus`를 관제 대시보드로 바꿨습니다. 기존 16단계 내용(등록 기기·현재 세션·알림·도움정보)은 맨 아래 「상세 근거」로 옮겼고 지우지 않았습니다. AI·패키지 카드는 `renderAiConnection`·`renderVulnerabilities`가 받은 값을 함께 씁니다. 13~20의 다른 함수 결과는 바꾸지 않았습니다. |
| `student/appearance.json` (새 파일) | `{"schema":"alekov.student-appearance.v1","dashboardPreset":"student-first"}`. 제공 배치 기능으로 학생 카드를 각 탭 제목 바로 아래로 올립니다. 학생 카드끼리의 순서는 그대로라서, 보호 현황에서는 로그인 카드 묶음이 대시보드보다 먼저 나옵니다. |

제공 파일(`public/`, `src/`, `tools/`, `package.json`)은 고치지 않았습니다.

## 4. 실행 명령

```powershell

node -v                                    # v22~24 (이 PC: v24.21.0)
node --check .\student\extension.mjs       # 출력이 없으면 통과
```

## 6. 아직 안 되는 것과 한계

- 기존 서버(SDP), 계정 연결·AI 점검·AI 설명, 조치 집행, 실제 OSV 조회는 여전히 연결되지 않았습니다(미확인).
- 추이는 앱을 연 동안만 남습니다. 날짜를 넘긴 추이나 저장된 기록이 아닙니다.
- CPU는 짧은 표본 한 번입니다. 원인을 말하려면 어떤 프로그램인지 더 확인해야 합니다.
- Windows 기록은 건수만 셉니다. 기록 내용은 이 조회에 없으므로 침해 판정이 아닙니다.
- 서비스(GitHub 등) 연결·사용량·비용은 학생 코드에서 서버 쪽 비밀값을 둘 수 없어 만들지 않았습니다.
- 키보드 확인은 Chrome에서 보호 현황의 두 버튼만 했습니다. 처음 보는 사람의 사용 관찰(권장 4단계), 200% 확대, 화면 낭독기 검수는 아직 하지 않았습니다.
